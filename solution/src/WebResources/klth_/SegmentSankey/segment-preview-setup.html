            Interactive steps that Microsoft requires

              Required: Add Customer Insights – Journeys data to Fabric

              Behavioral and Interaction queries require the Journeys interaction data. Complete this one-time Microsoft Fabric setup, then Segment Preview will create and maintain the queryable event tables automatically.

              Important: Choose Files, not Tables. Segment Preview reads the interaction data from Files/Customer Insights Journeys and creates the queryable journeys SQL tables itself. Shortcuts added under Tables cannot be detected by this setup.

              Use workspace the configured workspace and Serving Lakehouse the configured Serving Lakehouse.

              1. Open Microsoft Fabric, then open the workspace and Serving Lakehouse shown above. The workspace must use Fabric or Power BI Premium capacity.
              2. In the Lakehouse select Get data → New shortcut, then choose Dataverse.
              3. Select or create the connection for this Dataverse environment. The connection credential must have the System Administrator role in Dataverse.
              4. In the Dataverse source browser expand the Customer Insights Journeys folder and select the available interaction types that Segment Preview should query (select all available types for complete query coverage). Microsoft creates each selected interaction type as its own shortcut. Do not select the regular CDS2 Dataverse tables for this step.
              5. When Fabric asks whether to add the shortcuts under Files or Tables, explicitly choose Files. Keep the default Customer Insights Journeys destination hierarchy.
              6. Return to this Setup page and select Install everything. Setup will detect the export layout, run the bootstrap notebook immediately, and verify the generated journeys tables.
              Expected result: The Lakehouse contains Files/Customer Insights Journeys, and Setup reports one or more Journeys event tables as installed.
