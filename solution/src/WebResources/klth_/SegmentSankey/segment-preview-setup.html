One-click installation

Enter the target subscription and Fabric workspace once, then press Install everything. The setup center generates the API key, deploys the Azure resources, prepares Fabric, and writes the environment variables of this solution. Everything it creates is owned by your own tenant and subscription; no data and no resource leaves them.

Connect this environment

Installing uses a single-page application that you register once in your own tenant. This page shows the exact redirect URI and permissions and opens the Microsoft Entra admin center for you. Every resource the installation creates stays in your tenant and your subscription, and nothing is installed on your computer.

        Optional: mirror the API package yourself

        The installation downloads the published API package once, checks it against the SHA-256 digest below, then copies the verified bytes into a storage account in your own resource group. From that moment the Web App only ever reads the copy you own. Leave this empty to use the package that ships with this version. If your organisation mirrors release assets, paste the https URL of your own copy together with the SHA-256 of that exact file.
